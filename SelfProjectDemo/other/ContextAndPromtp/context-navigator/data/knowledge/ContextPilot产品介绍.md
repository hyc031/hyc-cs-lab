# Context Pilot 产品介绍

Context Pilot（上下文领航员）是一款面向开发者和 AI 产品团队的大模型上下文管理演示与实验工具。它把大模型对话中不可见的 Context（上下文）变成可视化的结构面板，帮助用户直观理解 KV Cache、上下文窗口、RAG 检索增强和工具调用的工作原理。

## 核心功能

1. **上下文结构可视化**：将 System Prompt、对话历史、RAG 检索结果、工具调用记录四类上下文成分分区块展示，每块实时显示 Token 占用与占比。
2. **KV Cache 模拟**：每轮对话自动判定缓存命中（Cache Hit）或未命中（Cache Miss），命中时复用已计算的前缀，未命中时重新计算，帮助理解前缀缓存机制。
3. **窗口溢出策略实验**：当上下文逼近窗口上限时，提供三种处理策略——删除历史、摘要压缩、智能裁剪，并可对比三者保留信息的差异。
4. **RAG 知识库**：内置基于 LangChain + FAISS 的向量检索知识库，用户提问时自动检索相关知识并注入上下文。
5. **MCP 工具调用**：通过 MCP 协议接入外部工具（如高德地图），工具调用过程与返回结果完整记录在上下文面板中。

## 适用场景

- 大模型应用开发教学与培训演示
- 面试或汇报时讲解 Context 工程、Prompt 工程
- 调试 RAG 应用时观察检索内容与上下文拼装顺序
- 对比不同窗口管理策略对信息保留的影响
