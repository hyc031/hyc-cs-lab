# Context Pilot 定价方案

## 免费版（Community）

- 价格：0 元
- 上下文窗口：2048 Token（演示配置）
- 功能：完整演示模式、上下文可视化、KV Cache 模拟、三种窗口策略体验
- 限制：知识库条目上限 10 篇文档，不支持自定义 MCP 服务

## 专业版（Pro）

- 价格：29 元 / 月，或 249 元 / 年
- 上下文窗口：可配置至 128K Token
- 功能：免费版全部功能，另加：
  - 自定义 RAG 知识库（不限文档数量）
  - 自定义 MCP 工具服务接入
  - 多会话管理与历史导出
  - Token 用量统计报表
- 适合个人开发者与小型团队

## 团队版（Team）

- 价格：99 元 / 人 / 月
- 功能：专业版全部功能，另加团队共享知识库、权限管理、审计日志
- 适合 10 人以上团队

## 教育优惠

高校师生凭教育邮箱可申请免费一年的专业版授权。
